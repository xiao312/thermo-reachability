# Thermochemical reachability: local-agent handoff

1. Extract this handoff bundle into a local working directory.
2. Open that directory with your local coding/research agent.
3. Paste the contents of `START_MESSAGE.txt` into the agent.

`LOCAL_AGENT_PROMPT.md` is the full scientific and execution specification. Its mandatory first tranche is Phases 0–3; the later phases are a follow-on research program, not prerequisites for the first report.

`thermochemical_compute_check.zip` preserves the earlier sandbox smoke-test package. Its `results.json` is historical evidence from that environment. The local agent must generate a new result file to claim local reproduction. The full prompt also contains enough equations to reconstruct the toy checks if those dependency pins do not fit the new environment.

This bundle is a research brief plus previously executed smoke tests. It does not contain a newly implemented detailed-chemistry solver, completed reachability study, or new counterflow results.
