# ThermoReachability

Code, script results, and logs for the ThermoReachability project.

## Layout

| Path | Contents |
|------|----------|
| `code/` | Source code and scripts |
| `results/` | Important script outputs (tables, figures, data) |
| `logs/` | Execution logs from runs on the compute server |

Computation is executed on a remote server; this repository is the shared
record of code and results so collaborators can inspect progress from GitHub
alone.

## Workflow

1. Develop and run code on the compute server.
2. Copy the code plus important results/logs into this repository.
3. Commit and push so the work is inspectable without server access.
